- **Primary Mark**: Ornate mannequin dress form in open L-bracket frame with scrollwork

## Usage

1. **Clone** this repository
2. Open any `.html` file in a browser to view the design system
3. Copy CSS variables from color/typography systems into your project
4. Use PNG assets directly in your application
5. Reference SVG code from graphics kit for inline icons
6. Follow brand guidelines for consistent application
