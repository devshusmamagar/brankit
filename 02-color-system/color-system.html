Usage Rules

DO: Gold on Dark

Use gold (#C9A961) text and accents on dark backgrounds (#1A1A1A, #5D4E37) for premium contrast and readability.

DON'T: Gold on White

Never use gold text on white or cream backgrounds. Contrast ratio is only 2.1:1 — fails WCAG AA. Use brown or dark instead.

DO: Cream Backgrounds

Use cream (#FAF8F5) as the primary page background for a warm, luxurious feel while maintaining text readability.

DON'T: Overuse Gold

Gold should accent, not dominate. Limit gold to CTAs, highlights, borders, and decorative elements. Never use for body text on light backgrounds.

DO: Brown for Text

Use brown (#5D4E37) for secondary text, dark (#1A1A1A) for primary text on light backgrounds. Both pass WCAG AA on cream/white.

DON'T: Rainbow Accents

Only use semantic colors (success, error, warning, info) for their intended purpose. Never use them as decorative accents alongside brand gold.
